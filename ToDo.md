## Home page

The scene is a table, a set of books rest on it, spines facing toward the user. One for each section: events, experiments, etc.
A stack of books, one for events, one for etc. And a flask bubbling next to it. When the user clicks on one it reshuffles based on where it is. and then opens, the others restack. And we see the options appear on the page. If the user clicks on the experiments the flask starts bubbling, smoke fills the screen and clears opening the experiments page.

## Experiments page

Shelf with bubbling flasks and each experiment labeled. As the list of experiments grow users can use the ladder to scroll up and down the shelves and we do some kind of state magic to get the next experiments and frustrum cull/ garbage collect the others.

## Login page

Open book and you need to type in the password, as you type the quill (waving gently in imagined wind) writes. A correct password cascades feathers down, landing on the book and a whirlwind takes you to the right page. The wrong password burns the book and the whole page goes up in flames.
