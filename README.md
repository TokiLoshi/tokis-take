# Toki's Takes ✨

My notes from the three.js conference, plus small shader experiments, on a site that tries not to feel flat.

## What's inside

- **Notes:** I write talks in Markdown, and a small parser turns them into pages.
- **Experiments:** shader sketches and small 3D tests, where I try ideas out.
- **A hidden page:** a secret phrase unlocks the three.js events page. Just for fun.

## How it works

- TanStack Start (React, TypeScript) with Tailwind
- A custom Markdown parser for the notes
- [Three.js / R3F, whichever you used] for the sparkles and shaders
- Cookieless PostHog analytics: no banner, no recordings
- Deployed on Netlify
